# Public history projection

This history retains the dates, authors, messages and ordering of 41 original
project commits beginning on 8 August 2026. File contents are restricted to
selected original documentation, protocols, analysis code, aggregate results,
figures and manuscript material. Some original commits become empty after
this restriction; they are retained as milestones, not represented as full
public reproductions of the private implementation work.

Commit hashes change when trees or ancestors change. The complete original
history and experimental evidence are retained privately. No old commit is
claimed to be bit-identical to its filtered public counterpart. Historical
README links can point to excluded material, and old scientific interpretations
may have been superseded; use the current report and archive instructions.

The current analysis-only snapshot is under `analysis-release/`. It reproduces
statistics, tables, figures and PDFs, not firmware, hardware, correctness tests
or disassembly audits. Inputs, kernels, native binaries, full disassemblies,
console captures and internal review conversations are outside this public
projection. Short attributed excerpts in the authored report remain.

This is a local candidate for the existing GitHub repository, not a new GitHub
repository. It is not public or deposited, and no DOI is claimed here. GitHub
may retain old cached objects after a force push; local filtering alone does
not certify their deletion from GitHub storage.
